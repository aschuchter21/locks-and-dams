# Gate Control Node settings - dev.14

Aim at the Gate Control Node and press Sneak + Use. With the usual sneak binding
and Use bound to R, this is Left Shift + R. The block and link-tool hints display
your actual bindings, including a remapped sneak key.

The settings gesture works with empty hands, a block or tool in the main hand,
and an occupied offhand. Normal Use with the Control Link Tool still links the
node. The settings screen selects the upper or lower gate; changes apply immediately.

Verification used a real local Minecraft client with Use temporarily bound to R,
checked all four held-item cases, and changed settings through the actual menu.
The test ran in an isolated preview world and restored its original key binding.

The proposed industrial desk redesign is a separate approval preview. Dev.14
retains the existing desk models, control positions, outputs and timing.
