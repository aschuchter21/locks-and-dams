# Desk design review

This is a proposal, not runtime mod art. Run Blender in background mode with
`blender_desk.py`, then run `package_preview.py` with Python. The editable Blender
source, GLB, rendered image and standalone interactive preview are written to
`design-review/Control-Desk-Design` in the repository. The HTML uses Three.js from
esm.sh. None of these files are included in the mod JAR.

Retain the existing three-part desk layout, center-front E-stop hit region,
end outputs, labels, selector meanings and timings when this design is approved.
